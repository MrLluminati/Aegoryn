Current position:

- Aegoryn passed the preliminary public-market conflict check better than several earlier candidates.
- It is not formally cleared.
- Formal trademark clearance is required before public launch, investor pitch, major branding spend, or app-store publication.

Recommended formal search classes:

| Class | Relevance |
|---|---|
| Class 9 | Software, mobile apps, downloadable software |
| Class 35 | Business/admin/productivity services |
| Class 36 | Finance/account tracking features |
| Class 38 | Communication/chat services, if applicable |
| Class 42 | SaaS, AI software, cloud services |
| Class 45 | Personal/lifestyle assistant services, legal-adjacent services |

Search sources to use before launch:

- IP India Trademark Public Search;
- WIPO Global Brand Database;
- USPTO Trademark Search;
- EUIPO / TMview;
- Google Play Store;
- Apple App Store;
- domain availability;
- MCA company-name availability if incorporating in India.
