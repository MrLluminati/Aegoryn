# v0.1.2-supabase-connect Release Notes

Date: 2026-05-09

Tag target commit: `64d0879`

## Summary

This checkpoint connects the MVP app to Supabase locally, adds the login page, and verifies the dashboard against live Supabase account-management records.

## Added

- Supabase public environment helpers.
- Browser client integration with validated public environment values.
- Supabase setup status page at `/setup/supabase`.
- Initial TypeScript row types.
- Account, money-bucket, and transaction fetch helpers.
- Supabase login page at `/login`.
- Dashboard reads for accounts, pocket money, and recent transactions.
- API role grants migration for authenticated Data API access.

## Changed

- `.env.example` supports Supabase publishable keys with a legacy anon-key fallback.
- Setup docs prioritize VS Code and PowerShell 7.
- Project registry records Supabase project details without secrets.

## Security

- Supabase RLS migration was recorded as successfully run.
- Authenticated Data API grants were applied while anonymous users remained blocked from private MVP tables.

## Verification

- `/setup/supabase` rendered locally.
- Hosted Supabase tables were verified in Table Editor.
- Test Auth user was created.
- Initial account-management seed data was inserted and verified.
- Dashboard loaded live Supabase account, pocket-money, and transaction records.
- Production build passed before tagging.

## Known Limitations

- User-specific RLS testing with a second user was still pending.
- Account ledger UI was not yet available.
- Chat parser was not yet implemented.
