# v0.1.0-mvp-start Release Notes

Date: 2026-05-09

Tag target commit: `1c44bb4`

## Summary

This checkpoint starts the working MVP app. It introduces the initial Next.js/Tailwind/TypeScript scaffold and the first static app screens.

## Added

- Next.js package manifest.
- Next.js config.
- TypeScript config.
- PostCSS config.
- Tailwind CSS config.
- Global styles.
- Root layout.
- Landing page shell.
- Dashboard shell.
- Static chat assistant shell.
- Supabase browser client helper.
- Reproducible `package-lock.json`.

## Changed

- Tailwind CSS was pinned to v3.4.x for compatibility with the current PostCSS setup.
- Early scaffold dependencies were simplified to unblock local installation.
- MVP backlog and setup docs were updated for the app scaffold.

## Verification

- Local scaffold run was recorded.
- Production build passed before tagging.

## Known Limitations

- Screens were static.
- Authentication was not implemented.
- Dashboard was not connected to Supabase.
- Chat parser was not implemented.
