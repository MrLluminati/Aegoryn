# v0.1.3-account-ledger Release Notes

Date: 2026-05-09

Tag target commit: `0be8f81`

## Summary

This checkpoint adds the first working account-ledger surface with manual transaction creation and audit-preserving reversal safety.

## Added

- Supabase-backed account ledger page at `/accounts`.
- Manual transaction form with date, type, amount, account, bucket, category, description, and source text.
- Account and money-bucket balance updates for manual entries.
- Ledger reversal flow that creates correction entries instead of deleting original records.
- Multiple-reversal blocking rule.
- Supabase GitHub integration timing rule.
- Supabase production-readiness workflow notes.
- Future visual analysis and expert assistant roadmap notes.

## Changed

- Dashboard savings metric now uses a Savings bucket when available.
- PRD and roadmap now emphasize chat-first UX, visual analysis, and future expert modules.
- Account ledger UI explains the no-silent-delete safety rule.

## Security

- Financial audit history is preserved through reversal entries.
- Reversal flow blocks repeat reversal of the same transaction.

## Verification

- Manual transaction creation was verified locally.
- Transaction reversal safety was verified locally.

## Known Limitations

- Ledger writes were still separate client-side operations at this checkpoint.
- Atomic RPC ledger writes were added later in `v0.1.4-auth-nav-shell`.
- Tasks, projects, and usage credits were still pending.
